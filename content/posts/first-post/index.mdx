はじめまして。nosuke と申します。

最近 Web まわりの技術に触れることが多くなってきたので、せっかくなら自分のサイトを立ててみようと思い、作りました。学生時代の知人の「一人一つはドメインを持つべき」という過激思想に洗脳され、すでにドメインを持っていた、というのも理由のひとつです。

## このサイトについて

このサイトは Cloudflare Workers でホストし、Hono（JSX）で構築しています。Cloudflare の無料枠の手厚さはありがたいですね。どうやって成り立っているのか、永遠の謎です。

記事はすべて Markdown で書いていて、ビルド時に静的な HTML にしてから配信しています。表示はできるだけ速く、書くのは気楽に。そんな方針で、少しずつ手を入れていこうと思っています。Astro などを使うのが一般的だと思いますが、そのような本格的な Web フレームワークは使いたくないな、という無駄なこだわりです。

ちなみに、ヘッダーのアニメーションは Anthropic のホームページのオマージュです。また、このサイトにはちょっとした隠し要素も２つ仕込んでいます。よかったら探してみてください。（ヒント：ブラウジングしてるとたまに遭遇するアレ）

## 趣味とこれから書くこと

趣味はいろいろあって、たとえば次のようなものです。

- 旅行
- 写真
- 読書
- ガジェットいじり
- 技術系の話

こうした内容を中心に、気が向いたときに記事を書いていければと思っています。

## 写真のこと

特に写真は、せっかく撮っても HDD の肥やしになるばかりで、ほとんど活用できていません。その供養もできたら、というのもこのサイトの目的のひとつです。

実は、写真を久々に Instagram に上げようかと考えていたところ、気に入っている写真が横写真ばかりで、少し相性が悪いなと感じていました。その点、Web サイトなら横写真も自然に見せられそうだなと思った次第です。それもこのサイト制作に至った動機の一つです。
